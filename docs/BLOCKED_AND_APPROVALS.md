# Blocked and Approvals

A blocked task is a healthy state. It means the agent refused to guess.

## Good blocked report

```text
Blocked:
Decision needed:
Options:
Risk:
Recommended next action:
```

## Bad blocked report

```text
stuck
```

## Approval boundary

If a task needs an external side effect that was not approved in the task body, block and ask for approval. Do not silently proceed.
