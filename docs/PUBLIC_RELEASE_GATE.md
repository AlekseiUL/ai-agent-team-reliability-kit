# Public Release Gate

Before publishing an AI agent/tool repository, verify it is public-safe.

## Minimum checklist

- README explains what the project is and who it is for.
- LICENSE exists and is appropriate.
- NOTICE.md names canonical source and attribution.
- SECURITY.md describes sensitive-data boundaries.
- Tests or offline checks run.
- No secrets, `.env`, auth stores, cookies, browser profiles, recordings, transcripts, private screenshots, or local paths.
- No generated bytecode/cache artifacts.
- No legal accusation wording unless legal review approved it.
- Public images/media only under intentional public asset paths like `docs/assets/`.

Run:

```bash
agent-team-reliability scan-repo .
```

Then do a human review. The scanner is a guardrail, not a legal or security guarantee.
