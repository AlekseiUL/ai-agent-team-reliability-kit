# Verification Gate

“Done” means the result was exercised or checked.

## Examples

Coding task:

```text
Verification required: unit tests pass, lint/syntax check passes, git status reviewed.
```

Public release task:

```text
Verification required: tests pass, privacy scan 0 findings, README/NOTICE/SECURITY/license present, release URL verified.
```

Research task:

```text
Verification required: sources listed, claims tied to evidence, uncertainty and gaps stated.
```

Document task:

```text
Verification required: links checked, spelling/readability pass, final artifact path provided.
```

## Anti-patterns

- “Looks good.”
- “I think it works.”
- “Should be fine.”
- No command output, no file path, no source list, no test result.
