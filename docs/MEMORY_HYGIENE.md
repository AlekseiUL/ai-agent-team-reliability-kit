# Memory Hygiene

Agent memory is not a task log.

## Keep in task board

- temporary progress;
- raw logs;
- one-off task details;
- stale artifact paths;
- intermediate failed attempts.

## Put in reports

- dated evidence;
- research outputs;
- smoke-test results;
- release summaries;
- decision records tied to a date.

## Put in wiki / durable docs

- operating rules;
- recovery procedures;
- source-of-truth boundaries;
- reusable workflows;
- team role changes.

## Put in memory

Only short, stable facts that prevent repeated mistakes.
